# cattle-data-recording

These pages provide tools to record mobility scores and lesions on a farm. The entered data can be downloaded as a CSV file and easily read into Excel or any other data analysis software. 

The Lesion scoring system is based on the supplementary material provided by Kofler et al. in their paper "Benchmarking claw health across three dairy cow breeds in 508 dairy farms using numerical claw health indicators"

[https://doi.org/10.1016/j.tvjl.2024.106242]
